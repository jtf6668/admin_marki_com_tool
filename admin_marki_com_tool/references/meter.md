# 抄表模块

本模块包含所有与水表/电表抄表和读数查询相关的功能和处理流程。

## 可用命令

| 功能 | 命令 |
|------|------|
| 智能抄表（推荐） | `python3 {baseDir}/scripts/main.py meter_reading <收费系统名称> <小区名称> <房屋关键词> <仪器类型> <读数> [备注]` |
| 查询电表/水表当前读数（推荐） | `python3 {baseDir}/scripts/main.py get_meter_status <收费系统名称> <小区名称> <房屋关键词> <仪器类型>` |

---

## 分情况处理流程

### 情况 1：用户进行抄表
**用户示例**：
- "帮我对1栋/1单元/101的电表进行抄表，本期读数是344.5"
- "给2栋3单元205的水表抄表，读数500，备注：2026年3月抄表"
- "抄表，1栋2单元301，电表，读数1234"

**处理步骤**：
1. 解析用户请求，提取：收费系统名称、小区名称、房屋位置关键词、仪器类型（水表/电表）、本期读数、备注
2. 如果信息完整，直接调用 `meter_reading <收费系统名称> <小区名称> <房屋关键词> <仪器类型> <读数> [备注]`
3. 如果信息不完整，按照通用流程逐步询问用户缺失的信息
4. 展示抄表结果给用户

**匹配规则说明**：
- 房屋匹配规则与"查询房屋/楼栋/单元欠费"的规则一致（参见欠费查询模块）
- 当有多个匹配的房屋时，会列出供用户选择
- 当房屋有多个同类型仪器时，会列出供用户选择

---

### 情况 2：用户查询电表/水表当前读数
**用户示例**：
- "帮我查询1栋/1单元/101的电表的读数"
- "查一下2栋3单元205的水表当前读数是多少"
- "当前读数，1栋2单元301，电表"

**处理步骤**：
1. 解析用户请求，提取：收费系统名称、小区名称、房屋位置关键词、仪器类型（水表/电表）
2. 如果信息完整，直接调用 `get_meter_status <收费系统名称> <小区名称> <房屋关键词> <仪器类型>`
3. 如果信息不完整，按照通用流程逐步询问用户缺失的信息
4. 展示查询结果给用户

**匹配规则说明**：
- 房屋匹配规则与"查询房屋/楼栋/单元欠费"的规则一致
- 当有多个匹配的房屋时，会列出供用户选择
- 当房屋有多个同类型仪器时，会列出供用户选择
