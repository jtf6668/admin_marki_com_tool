# 报表数据模块

本模块包含所有与收入、支出、收缴率统计相关的功能和处理流程。

## 可用命令

| 功能 | 命令 |
|------|------|
| 查询小区今日收入统计 | `python3 {baseDir}/scripts/main.py get_today_stats <收费系统名称> <小区名称>` |
| 查询小区自定义时间范围收入统计 | `python3 {baseDir}/scripts/main.py get_custom_range_stats <收费系统名称> <小区名称> <开始日期> <结束日期>` |
| 查询小区本月支出统计 | `python3 {baseDir}/scripts/main.py get_monthly_expense <收费系统名称> <小区名称>` |
| 查询小区本月收缴率统计 | `python3 {baseDir}/scripts/main.py get_collection_rate <收费系统名称> <小区名称>` |
| 通过小区ID查询今日收入统计 | `python3 {baseDir}/scripts/main.py get_community_today_stats <小区ID>` |
| 通过小区ID查询自定义时间范围收入统计 | `python3 {baseDir}/scripts/main.py get_community_custom_range_stats <小区ID> <开始时间戳> <结束时间戳>` |
| 通过小区ID查询本月支出统计 | `python3 {baseDir}/scripts/main.py get_community_monthly_expense <小区ID>` |
| 通过小区ID查询本月收缴率统计 | `python3 {baseDir}/scripts/main.py get_community_collection_rate <小区ID> <收费系统ID>` |

---

## 自定义时间范围查询说明

同欠费查询模块，AI 需要将用户任意格式的时间表述转换为标准 `YYYY-MM-DD` 格式。

支持的用户输入格式：
- "2025年1月到2026年12月"
- "去年到今年"
- "25年1月到今年2月"
- "2025/12/1-2026/3/1"
- "本月"、"上月"、"去年"、"本周"、"上周"
- "第一季度"、"第二季度"、"第三季度"、"第四季度"

## 分情况处理流程

### 情况 1：用户查询今日收入统计
**用户示例**：
- "今天小区总收入多少元？"
- "今天小区现金收入多少元？"
- "今天小区预存款充值了多少元？"
- "今天小区押金收取了多少元？"
- "今天小区有多少笔缴费？"
- "今天小区各个收费项的收入情况是怎样的？"
- "今天小区各个支付方式的收入情况是怎样的？"
- "今天小区各个收款员的收入情况是怎样的？"

**处理步骤**：
1. 只要用户询问关于"今天"或"今日"的任何收入相关统计（总收入、现金收入、预存款充值、押金收取、缴费笔数、各收费项/支付方式/收款员收入情况等），都直接调用 `get_today_stats` 命令获取完整的今日收入统计
2. 如果信息完整（收费系统名称、小区名称都有），直接调用 `get_today_stats <收费系统名称> <小区名称>`
3. 如果信息不完整，按照通用流程逐步询问用户缺失的信息
4. 展示完整的统计结果给用户（结果中包含用户需要的所有信息）

---

### 情况 2：用户查询自定义时间范围收入统计
**用户示例**：
- "查询碧桂园小区2025年1月到2026年12月的收入统计"
- "查某小区上个月的收入情况"
- "查询本周小区总收入多少元？"
- "查询3月份小区各收费项的收入情况"
- "查询去年第四季度小区的收入统计"

**处理步骤**：
1. 只要用户询问的不是"今天"或"今日"的收入统计，而是明确提到了其他时间范围（如"本月"、"上月"、"本周"、"去年"、"某年某月"、"某季度"等），或者用户明确要求查询某个时间区间的收入，都应该调用 `get_custom_range_stats` 命令
2. **AI（你）负责理解用户输入的时间**，将其转换成标准的 YYYY-MM-DD 格式
3. 你需要把开始和结束日期都转成 YYYY-MM-DD 格式后再调用命令
4. 结束时间会自动设置为当天的 23:59:59
5. 如果信息完整（收费系统名称、小区名称、日期范围都有），直接调用 `get_custom_range_stats <收费系统名称> <小区名称> <开始日期> <结束日期>`
6. 如果信息不完整，逐步询问用户缺失的信息
7. 展示完整的统计结果给用户（结果中包含用户需要的所有信息）

---
