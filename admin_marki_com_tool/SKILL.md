# Admin Marki Tool
这个工具可以让 AI 通过 HTTP 接口访问马克智慧物业系统。

## 安装依赖
在使用前，请确保安装了所需的依赖包：
```bash
pip install -r {baseDir}/requirements.txt
```


# 使用方法

## 核心原则
- **对用户只展示名称，不展示 ID**
- **静默选择原则：当只有一个选项时，直接使用，不展示也不询问用户**
- **根据用户提供的信息完整程度，采取不同的处理流程**
- **当用户信息不完整时，先调用相应命令获取选项，若只有一个则静默使用，有多个时才询问用户**
- **记住用户的选择：同一对话中，记住用户上次使用的收费系统和小区，优先使用**
- **当搜索房屋找不到精确匹配时，系统会返回候选列表（CANDIDATES: 格式）**
  - 首先尝试智能判断哪个候选最符合用户输入
  - 如果不确定，列出候选让用户选择
  - 候选列表会按相关程度排序，如果用户提到了楼栋号，会优先显示该楼栋下的房屋

## 对话风格规范
- **禁止使用的话术**：
  - "根据SKILL.md要求..."
  - "让我先列出可用的收费系统..."
  - "找到了一个可用的收费系统..."
  - 其他暴露内部处理流程的话术
- **推荐使用的话术**：
  - "好的，我来帮您查询..."
  - "请问您想查询哪个小区？"
  - "我找到了多个收费系统，请您选择一下："
- **整体语气**：专业、简洁、高效，符合物业管理人员的日常工作习惯
- **回复原则**：直接执行操作，静默使用单一选项，只在必要时询问用户


## 登录提示处理

当运行任何命令后，如果输出包含 `AUTH_REQUIRED` 标记，表示用户需要先登录。请按以下格式处理登录提示：

1. 首先查找 `LOGIN_URL:` 开头的行，获取完整的登录链接
2. 查找 `MESSAGE:` 开头的行，获取提示消息
3. 按照以下格式展示给用户：

```
{MESSAGE的内容}

🔗 登录链接：{LOGIN_URL的内容}

登录成功后，请再次询问我即可继续查询。
```

**重要：**
- 只展示 `LOGIN_URL:` 后面的完整链接，这是用户真正需要点击的链接
- **不要**展示任何 `http://localhost:8080/callback` 这样的本地回调链接
- 确保链接可以直接点击访问


## 可用命令

AI 应当根据需求选择以下指令运行：

- **查看我加入的团队列表信息**: `python3 {baseDir}/scripts/main.py get_my_team`
- **登出马克账号**: `python3 {baseDir}/scripts/main.py logout`
- **列出可用的收费系统**: `python3 {baseDir}/scripts/main.py list_charge_systems`
- **搜索小区**: `python3 {baseDir}/scripts/main.py search_community <收费系统名称> <小区关键词>`
- **通过名称查询欠费总额（推荐）**: `python3 {baseDir}/scripts/main.py get_arrears <收费系统名称> <小区名称>`
- **通过名称查询本年度物业费欠费**: `python3 {baseDir}/scripts/main.py get_current_year_arrears <收费系统名称> <小区名称>`
- **通过名称查询自定义时间范围欠费**: `python3 {baseDir}/scripts/main.py get_custom_range_arrears <收费系统名称> <小区名称> <开始日期> <结束日期>`
- **查询小区今日收入统计**: `python3 {baseDir}/scripts/main.py get_today_stats <收费系统名称> <小区名称>`
- **查询小区自定义时间范围收入统计**: `python3 {baseDir}/scripts/main.py get_custom_range_stats <收费系统名称> <小区名称> <开始日期> <结束日期>`
- **查询小区本月支出统计**: `python3 {baseDir}/scripts/main.py get_monthly_expense <收费系统名称> <小区名称>`
- **查询小区本月收缴率统计**: `python3 {baseDir}/scripts/main.py get_collection_rate <收费系统名称> <小区名称>`
- **查询小区欠费户数统计**: `python3 {baseDir}/scripts/main.py get_arrear_households <收费系统名称> <小区名称>`
- **查询房屋/楼栋/单元欠费总额**: `python3 {baseDir}/scripts/main.py get_household_arrears <收费系统名称> <小区名称> <关键词>`
- **查询当前登录用户信息（推荐，无需参数）**: `python3 {baseDir}/scripts/main.py get_current_user_info`
- **查询当前登录用户完整信息**: `python3 {baseDir}/scripts/main.py get_current_user_info <收费系统名称> <小区名称>`
- **发送微信缴费提醒（推荐）**: `python3 {baseDir}/scripts/main.py send_wechat_reminder <收费系统名称> <小区名称>`
- **通过小区ID发送微信缴费提醒（旧版）**: `python3 {baseDir}/scripts/main.py send_community_wechat_reminder <小区ID>`
- **智能抄表（推荐）**: `python3 {baseDir}/scripts/main.py meter_reading <收费系统名称> <小区名称> <房屋关键词> <仪器类型> <读数> [备注]`
- **查询电表/水表当前读数（推荐）**: `python3 {baseDir}/scripts/main.py get_meter_status <收费系统名称> <小区名称> <房屋关键词> <仪器类型>`
- **通过小区ID查询欠费总额（旧版）**: `python3 {baseDir}/scripts/main.py get_community_total_arrears <小区ID>`
- **通过小区ID查询本年度物业费欠费**: `python3 {baseDir}/scripts/main.py get_community_current_year_arrears <小区ID>`
- **通过小区ID查询今日收入统计**: `python3 {baseDir}/scripts/main.py get_community_today_stats <小区ID>`
- **通过小区ID查询自定义时间范围收入统计**: `python3 {baseDir}/scripts/main.py get_community_custom_range_stats <小区ID> <开始时间戳> <结束时间戳>`
- **通过小区ID查询本月支出统计**: `python3 {baseDir}/scripts/main.py get_community_monthly_expense <小区ID>`
- **通过小区ID查询本月收缴率统计**: `python3 {baseDir}/scripts/main.py get_community_collection_rate <小区ID> <收费系统ID>`
- **通过小区ID查询欠费户数统计**: `python3 {baseDir}/scripts/main.py get_community_arrear_households <小区ID>`
- **通过小区ID和收费系统ID查询初始化信息**: `python3 {baseDir}/scripts/main.py get_community_cs_init_info <小区ID> <收费系统ID>`

### 自定义时间范围查询说明

当用户查询自定义时间范围的欠费时：

1. **AI（你）负责理解用户输入的时间**，将其转换成标准的 YYYY-MM-DD 格式
2. 用户的时间表述可以是任意格式，例如：
   - "2025年1月到2026年12月"
   - "去年到今年"
   - "25年1月到今年2月"
   - "2025/12/1-2026/3/1"
   - "本月"、"上月"、"去年"
3. 你需要把开始和结束日期都转成 YYYY-MM-DD 格式后再调用命令
4. 结束时间会自动设置为当天的 23:59:59

## 分情况处理流程

### 情况 1：用户提供了完整信息查询总欠费
**用户示例**："查询波波测试收费系统里碧桂园小区的欠费"

**处理步骤**：
1. 直接调用 `get_arrears <收费系统名称> <小区名称>`
2. 展示结果给用户

---

### 情况 2：用户查询本年度物业费欠费
**用户示例**："查询波波测试收费系统里碧桂园小区今年的物业费欠费" 或 "查询某小区本年度物业费欠费"

**处理步骤**：
1. 确认用户是要查询"本年度物业费欠费"
2. 如果信息完整，直接调用 `get_current_year_arrears <收费系统名称> <小区名称>`
3. 如果信息不完整，按照下面的情况逐步询问用户
4. 展示结果给用户

---

### 情况 3：用户查询自定义时间范围欠费
**用户示例**："查询波波测试收费系统里碧桂园小区2025年1月到2026年12月的物业费欠费"、"查某小区去年到今年的欠费"、"查询25年1月到今年2月的欠费"

**处理步骤**：
1. 确认用户是要查询自定义时间范围的欠费
2. 提取用户提到的日期范围信息
3. 如果信息完整（收费系统名称、小区名称、日期范围都有），直接调用 `get_custom_range_arrears <收费系统名称> <小区名称> <日期范围>`
4. 如果信息不完整，逐步询问用户缺失的信息
5. 展示结果给用户

---

### 情况 4：用户只提供了小区名
**用户示例**："查询碧桂园小区的欠费" 或 "查询碧桂园小区本年度物业费欠费"

**处理步骤**：
1. 先调用 `list_charge_systems` 获取所有可用的收费系统
2. **如果只有一个收费系统**：直接使用，不展示也不询问用户
3. **如果有多个收费系统**：展示给用户选择
4. 使用收费系统后，调用 `search_community <收费系统名称> <小区名>` 确认小区
5. **如果只有一个匹配小区**：直接使用
6. **如果有多个匹配小区**：展示给用户选择
7. 根据用户需求调用相应命令并展示结果

---

### 情况 5：用户查询非常模糊
**用户示例**："查询当前小区欠费"、"查欠费"、"查今年的物业费"、"查小区收费情况"

**处理步骤**：
1. 先调用 `list_charge_systems` 获取所有可用的收费系统
2. **如果只有一个收费系统**：直接使用，不展示也不询问用户
3. **如果有多个收费系统**：展示给用户选择
4. 使用收费系统后，调用 `search_community <收费系统名称> ""` 获取该收费系统下的所有小区
5. **如果只有一个小区**：直接使用，不展示也不询问用户
6. **如果有多个小区**：询问用户："请问您想查询哪个小区？"
7. 用户选择小区后，根据用户需求调用相应命令
8. 展示结果给用户（可在结果开头简要说明查询的是哪个收费系统下的哪个小区）

---

### 情况 6：有多个匹配的小区
**用户示例**："查询波波系统里带有'花园'的小区欠费"

**处理步骤**：
1. 调用 `search_community <收费系统名称> <小区关键词>` 获取匹配的小区

4. 用户选择后，根据用户需求调用相应命令
5. 展示结果给用户

**用户示例**：
- "今天小区总收入多少元？"
- "今天小区现金收入多少元？"
- "今天小区预存款充值了多少元？"
- "今天小区押金收取了多少元？"
- "今天小区有多少笔缴费？"
- "今天小区各个收费项的收入情况是怎样的？"

2. 如果信息完整（收费系统名称、小区名称都有），直接调用 `get_today_stats <收费系统名称> <小区名称>`
3. 如果信息不完整，按照前面的情况逐步询问用户缺失的信息
4. 展示完整的统计结果给用户（结果中包含用户需要的所有信息）

### 情况 7.5：用户查询自定义时间范围收入统计
**用户示例**：
- "查询碧桂园小区2025年1月到2026年12月的收入统计"
- "查某小区上个月的收入情况"

   - "2025年1月到2026年12月"

   - "2025/12/1-2026/3/1"

   - "第一季度"、"第二季度"、"第三季度"、"第四季度"
4. 你需要把开始和结束日期都转成 YYYY-MM-DD 格式后再调用命令
5. 结束时间会自动设置为当天的 23:59:59
6. 如果信息完整（收费系统名称、小区名称、日期范围都有），直接调用 `get_custom_range_stats <收费系统名称> <小区名称> <开始日期> <结束日期>`
7. 如果信息不完整，按照前面的情况逐步询问用户缺失的信息
8. 展示完整的统计结果给用户（结果中包含用户需要的所有信息）

### 情况 11：用户查询房屋/楼栋/单元欠费

- "查一下3单元欠了多少钱"
- "101室欠费多少"
- "查A栋的欠费"

**处理步骤**：
1. 先确认小区信息（如不完整，按现有逻辑询问）
2. 调用 `get_household_arrears <收费系统名称> <小区名称> <用户的查询关键词>`
3. 如果返回 `MULTI_MATCH:` 开头的多个匹配项，列出给用户选择，并提示用户可以通过以下方式选择：
   - 输入序号（如 "1"、"2"）

   - 输入文字描述（如 "第一个"、"第二个"、"最后一个"）
   - 输入完整路径（如 "1栋/1单元/103"）
4. 用户做出选择后，将用户的选择作为新的关键词再次调用 `get_household_arrears <收费系统名称> <小区名称> <用户的选择>`
5. 展示最终欠费总额给用户

**匹配规则说明**：
- 模糊匹配会自动找出所有名称包含关键词的楼栋/单元/房屋
- 如果多个匹配项有层级关系（如同时匹配到"1栋"和"1栋A座"），会自动选择最高层级的"1栋"
- 如果多个匹配项之间没有层级关系（如同时匹配到"1栋"和"2栋"），会列出供用户选择
- 当用户输入包含 "/" 时，会优先进行精确路径匹配
- 系统会记住上一次的匹配列表（5分钟内有效），支持用户通过多种方式选择

### 情况 11.5：处理候选列表（CANDIDATES: 格式）

当查询房屋（欠费查询、抄表、查询读数）找不到精确匹配时，系统会返回候选列表格式：

```
CANDIDATES:
用户查询: <用户原始关键词>
候选列表:
1. 1栋/1单元/101
2. 1栋/1单元/102
3. 1栋/1单元/103
...
提示: 未找到精确匹配，请从以上候选中选择，或使用完整路径如"1栋/1单元/103"
```

**处理步骤**：
1. 首先仔细阅读候选列表和用户的原始查询
2. 尝试智能判断哪个候选最符合用户输入（例如用户说"一栋一单元103"，候选中有"1栋/1单元/103"就是最匹配的）
3. 如果非常确定某个候选是正确的，直接使用该候选重新调用命令，无需询问用户
4. 如果不确定，展示候选列表给用户，并请用户选择
5. 支持用户通过以下方式选择：
   - 输入序号（如 "1"、"2"）
   - 输入完整路径（如 "1栋/1单元/103"）

**中文数字支持**：
- 用户可能使用中文数字输入（如"一栋一单元103"），系统会自动转换为阿拉伯数字进行匹配
- 当看到用户使用中文数字时，优先选择对应阿拉伯数字的候选
